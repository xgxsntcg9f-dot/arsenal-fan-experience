# Arsenal Fan Experience

A football fan website created for the Frontend Development Final Project.

## Features

- Matchday image slider
- Dark mode
- Player gallery
- Fan voting system
- Match prediction form
- Quiz section
- Contact form preview
- Image lightbox

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Event Listeners
